How to Set Up a US Mobile Proxy in Dolphin Anty

This guide shows how to connect a BM USA PROXY mobile proxy to a Dolphin Anty browser profile, step by step. By the end you will have a profile that works through a real US carrier connection — AT&T, T-Mobile or Verizon — with its own IP-change link one click away.

Dolphin Anty takes the whole proxy as a single line of text, so the setup itself takes a couple of minutes. Most problems come from the format of that line, and the troubleshooting section at the end covers them.

What You Get From BM USA PROXY

When you sign up — a free trial is available before you pay — support sends your connection details in Telegram:

  • Protocol — HTTP(S) or SOCKS5
  • Host and port — the address of your proxy
  • Login and password
  • An IP-change link — opening it gives the device a new IP

You also choose the carrier — AT&T, T-Mobile or Verizon — and the city: Seattle, Portland, Los Angeles, Las Vegas, Phoenix, Denver, Dallas, Chicago, New York or Miami. Each proxy runs on a real SIM card in a physical Android phone. A dedicated device per client is standard, and a shared option exists too.

Don’t have the details yet? Message support on Telegram — access is usually set up within minutes.

Add the Proxy to a Dolphin Anty Profile

  1. Open the profile you want: click the three dots next to it and choose Edit, or create a new profile.
  2. In the proxy field, choose New Proxy.
  3. Paste the proxy as one line with the protocol in front:
    http://login:password@host:port for HTTP, or
    socks5://login:password@host:port for SOCKS5.
    Dolphin Anty also accepts the short form host:port:login:password.
  4. Wait for Dolphin Anty to check the proxy, then click Save.

The protocol at the start of the line has to match the one support gave you. A SOCKS5 proxy written with http:// in front will not connect.

Keep Proxies on the Proxy Screen

Besides the field inside a profile, Dolphin Anty has a separate Proxy screen with an Add Proxy button. A proxy saved there can be picked for any profile later and shared with teammates on the same account, and on paid plans it can be assigned to many profiles at once from the Bulk Profile Control Panel.

If you run profiles for several clients, keeping proxies on this screen makes it easy to see which carrier and city belongs to which client.

Check the Connection

Click the small arrows icon next to the proxy line. Dolphin Anty checks three things: that the connection works, the geolocation, and the time zone. For a BM USA PROXY connection the geolocation should show the United States.

To see which carrier and city you are on, start the profile and open any IP-lookup page inside it — it shows the ISP and the location of your US mobile IP.

Save the IP-Change Link

In the proxy settings there is a line called Link to change IP. Paste the IP-change link from your BM USA PROXY details there and save.

After that, Dolphin Anty shows an IP change button for this profile right on the profiles screen: one click gives the device a new IP, without opening the settings. The login and password stay the same, so the profile keeps working. If you prefer the IP to change on a schedule instead, support can set a timer on the device.

If the Check Fails

Wrong protocol. If the check fails at once, compare the prefix of your line — http:// or socks5:// — with the protocol support gave you.

Wrong order in the line. The two formats put the parts in a different order: login:password@host:port and host:port:login:password. Mixing them puts the password where the host should be. Copy the details from the Telegram message instead of retyping them.

The check hangs. Make sure the port was copied in full, and that your own network does not block outgoing proxy connections — some office and hotel networks do. Try again after a few seconds. If it still does not connect, write to support with the error text — they can confirm from their side that the device is online.

FAQ

Which line format does Dolphin Anty accept?

Both protocol://login:password@host:port and the short host:port:login:password. With the long form you set the protocol yourself, so it is the safer choice.

Should I choose HTTP or SOCKS5?

Use the protocol support assigned to you. Dolphin Anty works with both — what matters is that the prefix in the line matches.

Can one proxy be used in several Dolphin Anty profiles?

It depends on your plan: a dedicated device or a shared one. Ask support before connecting the same login to several profiles.

How do I get a new IP without editing the profile?

Open your IP-change link, or ask support to change the IP by timer. The login and password stay the same, so the profile keeps working.
