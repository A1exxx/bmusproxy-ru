How to Set Up a US Mobile Proxy in AdsPower

This guide shows how to connect a BM USA PROXY mobile proxy to an AdsPower browser profile, step by step. By the end you will have a profile that works through a real US carrier connection — AT&T, T-Mobile or Verizon — with its IP-change link saved right in AdsPower.

AdsPower has a field made specifically for mobile proxies: Change IP URL. This guide shows how to use it.

What You Get From BM USA PROXY

When you sign up — a free trial is available before you pay — support sends your connection details in Telegram:

  • Protocol — HTTP(S) or SOCKS5
  • Host and port — the address of your proxy
  • Login and password
  • An IP-change link — opening it gives the device a new IP

You also choose the carrier — AT&T, T-Mobile or Verizon — and the city: Seattle, Portland, Los Angeles, Las Vegas, Phoenix, Denver, Dallas, Chicago, New York or Miami. Each proxy runs on a real SIM card in a physical Android phone. A dedicated device per client is standard, and a shared option exists too.

Don’t have the details yet? Message support on Telegram — access is usually set up within minutes.

Add the Proxy to an AdsPower Profile

  1. Create a new profile, or open an existing one for editing, and go to its Proxy settings.
  2. Choose Custom — the option for a proxy you bring yourself.
  3. In Proxy type, select the protocol support gave you: HTTP, HTTPS or Socks5.
  4. Paste the whole line host:port:login:password into the Host:Port field — AdsPower fills in Proxy username and Proxy password by itself. You can also fill the fields one by one.
  5. Click Check Proxy, then save the profile.

Save the Change IP URL

AdsPower keeps a separate list of proxies on its Proxies page. When you add or edit a proxy there, you will find an optional field called Change IP URL — AdsPower’s documentation describes it as a field for mobile proxies only, which is exactly the case for BM USA PROXY.

Open the proxy on the Proxies page, paste the IP-change link from your BM USA PROXY details into Change IP URL, and save. From then on you can get a new IP without leaving AdsPower. The login and password stay the same, so nothing else in the profile needs to change. If you prefer the IP to change on a schedule instead, support can set a timer on the device.

Check the Connection

Click Check Proxy. AdsPower shows the outgoing IP and a status color: green when the check passed, red when it failed. For a BM USA PROXY connection the IP should be a US address.

To see which carrier and city you are on, start the profile and open any IP-lookup page inside it — it shows the ISP and the location of your US mobile IP.

Once the proxy works, you can pick it again from Saved Proxies when setting up other profiles, so the same carrier and city go into a new profile without entering the details twice.

If the Check Fails

Wrong proxy type. If the check fails at once, compare the Proxy Type you selected with the protocol support gave you — HTTP(S) or SOCKS5.

Details in the wrong fields. A password pasted into the login field, or the port left inside the host field, fails the check even when every value is correct. Copy the details from the Telegram message instead of retyping them.

The check hangs. Make sure the port was copied in full, and that your own network does not block outgoing proxy connections — some office and hotel networks do. If it still does not connect, write to support with the error text — they can confirm from their side that the device is online.

FAQ

Which option do I choose in the AdsPower proxy settings?

Custom — it is the option for a proxy you bring yourself. Saved Proxies is for proxies you have already added.

Should I choose HTTP or SOCKS5?

Use the protocol support assigned to you and select the same one in Proxy Type. AdsPower works with both.

Where is the Change IP URL field and what goes into it?

On the Proxies page, when you add or edit a proxy. Paste the IP-change link from your BM USA PROXY details: opening it gives the device a new IP while the login and password stay the same.

Can one proxy be used in several AdsPower profiles?

It depends on your plan: a dedicated device or a shared one. Ask support before using the same login in several profiles.
